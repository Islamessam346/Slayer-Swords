# Slayer Swords
        This mod is inspired by the Demon Slayer Anime. and adds multiple swords and material and crafting trees (coming soon)
        - water,flame,toxic,serpent, and black nichirins/swords
        - sun, scarlet Ores, and Ingots
        - wisteria, marine, volcanic, vortex ember, serpent scales materials

### Requirements

- Minecraft [26.1.2]
- [Fabric] Loader
- [Fabric API]

### Installing the mod

1. Install the required Minecraft version.
2. Install [Fabric] Loader for that Minecraft version.
3. Download the [slayerswords-1.0.0-26.1.2.jar] file from the repo.
4. Open your Minecraft `mods` folder:
   - **Windows:** `%APPDATA%\.minecraft\mods`
   - **macOS:** `~/Library/Application Support/minecraft/mods`
   - **Linux:** `~/.minecraft/mods`
5. Put the downloaded `.jar` file into the `mods` folder.
6. Launch Minecraft using the [Fabric] profile.
7. Start the game and verify that the mod is loaded.
